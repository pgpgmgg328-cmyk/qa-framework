# Памятка для Claude Code

Проект — агент T-Work v4.9: сам решает задания разметки на https://twork.tbank.ru, а с
`PLATFORM=ozon` — на Ozon Profit (https://task.ozon.ru) (Python 3.10+, Playwright, модели через OpenRouter). Пользователь работает на Windows и пишет
по-русски: отвечай по-русски, о сделанном рассказывай словами, без кода, если код не попросили.
Подробности — README.md (установка, `.env`, как работает агент) и AUDIT.md (что и почему
менялось по версиям).

## Обязательные правила

- Репозиторий **публичный**. Никогда не коммить и не выводить в чат: `.env`, ключи API,
  `.browser-profile/`, `knowledge/`, `logs/`, `recordings/` — там куки и личные данные. Содержимое
  записей и логов никуда не публиковать. В тестовых страницах — только вымышленные данные.
- Ветка — `claude/twork-agent-audit-kmtk5f`: коммитить и пушить только в неё. Pull request — только
  по просьбе пользователя. Сообщения коммитов — по-русски.
- В аккаунты (T-Work, Ozon ID и любые другие) входит только пользователь, сам, в окне браузера.
  Не вводи логины, пароли и коды из SMS и не проси их прислать: дошёл до входа или капчи —
  попроси пользователя и жди.
- «Выйти из задания», «Да, выйти», «Завершить смену» не нажимать никогда — ни агентом (стоп-список
  `FINISH_DENY_SUBSTRINGS` в `config.py`), ни самому через браузер.
- Брать задания, отправлять настоящие ответы, начинать экзамены и тесты — только когда пользователь
  рядом и согласен: ошибки снижают рейтинг и закрывают доступ к заданиям.
- Новая площадка: селекторы и тексты кнопок не угадывать — сначала изучить реальный сайт.
- Работа на T-Work не должна сломаться. Перед коммитом — полный прогон `python -m pytest`
  (сейчас `164 passed, 1 skipped`, 8–10 минут). Тесты открывают браузер на локальных страницах
  из `tests/fixtures`; к площадкам и к моделям не обращаются. Если в папке есть `.venv`, Python —
  `.venv\Scripts\python`. На компьютере пользователя Chromium Playwright не скачивается (CDN
  playwright не отвечает) — тесты запускать с `BROWSER_CHANNEL=chrome` (установленный Chrome).

## Устройство

| Файл | Что внутри |
|---|---|
| `main.py` | запуск: `python main.py` — агент; `python main.py --record [--url адрес]` — запись ручной работы |
| `agent.py` | цикл агента: смена заданий, инструкции, тренировка и экзамен, лестница моделей, отправка ответа |
| `browser_controller.py` | браузер с постоянным профилем `.browser-profile`, выбор фрейма задания (`find_target_frame`), клики, ожидания (`wait_settle`, `wait_for_network_idle_and_dom`) |
| `dom_parser.py` | снимок страницы для модели (`_JS_SNAPSHOT`, метки `data-agent-id`) |
| `openrouter_connector.py` | запросы к моделям, системный промпт, фото, аудио, документы |
| `knowledge.py` | база знаний `knowledge/`: инструкции, разборы ошибок, статистика тренировок |
| `documents.py`, `media.py`, `research.py` | PDF-инструкции; фото и аудио; поиск в интернете |
| `recorder.py` | режим записи |
| `config.py`, `models.py` | все настройки (читаются из `.env`) и модели данных |
| `adapters/` | площадки: `twork.py` (по умолчанию), `ozon_profit.py` (`OzonProfitAdapter`) |

Площадка — `PLATFORM=twork|ozon` в `.env`. Модуль площадки задаёт только значения по умолчанию
для настроек `config.py`, `.env` их перекрывает: `TARGET_URL`, `FRAME_KEYWORDS`, `ALLOW_MAIN_FRAME`,
`FINISH_BUTTON_TEXTS`, `TASK_URL_KEYWORDS` (проверяется по адресу без домена), `ORDERS_BUTTON_TEXTS`,
`ORDERS_DONE_TEXTS`, `NON_TASK_URL_KEYWORDS`, `WRONG_ANSWER_TEXTS`, `DIALOG_SELECTORS`,
`PAGE_SKIP_SELECTORS`, `POOL_URL_RE`, `EXTRA_DENY_SUBSTRINGS` (добавка к `FINISH_DENY_SUBSTRINGS`).
Общие для площадок: `START_BUTTON_TEXTS`, `DIALOG_CLOSE_TEXTS`. В тестах площадку включает
`tests.helpers.use_platform`; `tests/conftest.py` ставит `PLATFORM=twork`, что бы ни было в `.env`
(у пользователя там `PLATFORM=ozon`).

Профиль `.browser-profile` открывается только одним окном: агент, запись и свои скрипты с этим
профилем одновременно не запускать (ошибка «ProcessSingleton»).

## Текущая задача — Ozon Profit (https://profit.ozon.ru)

Пункты 1–3 сделаны (октябрь 2026): площадка изучена во встроенном браузере Claude Desktop,
поддержка — `PLATFORM=ozon`, что увидели и что сделано — AUDIT.md, «Ozon Profit». Задания — на
task.ozon.ru, в главном фрейме. Пользователь запускал агента (логи `logs/` 7.10) и записал свою работу
(`recordings/` 9.10, 346 экранов, ~15 проектов) — разбор и исправления в AUDIT.md. **Дальше:** проверить
агента на тренировках после исправлений; по записям — правила проектов в базу знаний и сверка ответов
агента с ответами пользователя; задания с рамкой на фото («Демо: разметка изображений») агент не умеет.
Автоклассификатор Claude Code не дал Claude самому выбирать ответы в заданиях даже с согласия
пользователя: отвечал пользователь, Claude читал страницу. Запуск агента на сайте — тоже
пользователь, сам.

Как шла работа (для следующих площадок):

1. **Изучить площадку.**
   - В браузере, доступном этой сессии: панель Browser приложения Claude Desktop (чистый профиль —
     в Ozon ID пользователь входит там сам) или Chrome пользователя через расширение Claude in
     Chrome (там он уже вошёл). Смотреть страницы и их устройство.
   - Записью: `python main.py --record --url https://profit.ozon.ru` — окно Playwright с профилем
     `.browser-profile`; пользователь входит сам и проходит 1–2 задания вручную. На каждом экране
     сохраняется `recordings/<сессия>/<NNN>_…/`: `frame.html`, `frames/*.html`, `components.json`
     (роли, aria- и data-атрибуты, классы, кнопки, переключатели, поля, диалоги, лоадеры и
     скелетоны, iframe), `screen.jpg`, `llm_view.txt` (что увидела бы модель), `state.json`,
     `actions.json` (действия пользователя).
   - Временные скрипты и дампы держать вне git (`recordings/` или временная папка) и удалить после
     работы.
   - Если Ozon не пускает окно Playwright (антибот, «Доступ ограничен») — попробовать
     `BROWSER_CHANNEL=chrome` в `.env`; капчу решает пользователь.
2. **Разобрать** записи: в каком фрейме задание (если в главном — `ALLOW_MAIN_FRAME`), как выглядят
   варианты ответа и их выбранное состояние, тексты кнопок начала, отправки и перехода, список
   заданий, инструкции, лоадеры, сообщения о проверке ответа. Сравнить с `llm_view.txt`: чего
   парсер не видит.
3. **Сделать поддержку.** Площадка выбирается настройкой в `.env`; T-Work остаётся по умолчанию.
   Общий код не дублировать — в модуль площадки выносить только то, что отличается. Тестовая
   страница — по образцу реальной структуры, с вымышленным содержимым (без имён, телефонов и
   адресов из записей); тесты на парсер и отправку.
4. **Проверить вживую** — только при пользователе (см. правила).
